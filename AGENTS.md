## Guiding Principles

* **Keep the surface small.** Only work on what’s necessary and on what the task is.
* Avoid bloat — too many layers of css abstraction make the code harder to maintain and often result in a bad design. Keep it simple, one line, apply css over it, simple.
* **Keep code lean.** Small, focused functions and modules. Build what’s needed right now — not what we *might* need later.
